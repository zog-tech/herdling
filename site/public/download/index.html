macOS and Linux

herdlingd, the companion

A single program that runs on your computer next to herdr. It answers the app over SSH, pairs phones and sends notifications. It runs as your user, as a background service.

Needs herdr (installed and running) and an SSH server. On macOS: System Settings › General › Sharing › Remote Login. On Linux: the OpenSSH server.

Build it from source

Herdling is open source (MPL-2.0). You need git, a C compiler (macOS: xcode-select --install; Debian and Ubuntu: sudo apt install build-essential) and Rust (stable), for example from rustup. herdr must be installed and running.

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
git clone https://github.com/zog-tech/herdling
cd herdling/companion
cargo build --release
./target/release/herdlingd install
herdlingd pair

herdlingd install copies the program to ~/.local/bin/herdlingd and starts the service: com.zogtech.herdlingd (launchd) on macOS, herdlingd.service (systemd user service) on Linux. Open a new terminal after rustup, and add ~/.local/bin to your PATH if herdlingd is not found. Then scan the QR code from herdlingd pair in the app. To update, run git pull, cargo build --release and install again.
