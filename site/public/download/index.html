macOS and Linux

herdlingd, the companion

A single program that runs on your computer next to herdr. It answers the app over SSH, pairs phones and sends notifications. It runs as your user, as a background service.

Needs herdr and an SSH server. On macOS: System Settings › General › Sharing › Remote Login. On Linux: the OpenSSH server.

It downloads herdlingd for your system and runs herdlingd install. Run it again to update.

Or install a build by hand

chmod +x ./herdlingd
./herdlingd install
herdlingd pair

herdlingd install copies the program to ~/.local/bin and starts the service: com.zogtech.herdlingd (launchd) on macOS, herdlingd.service (systemd user service) on Linux. Then scan the QR code from herdlingd pair in the app.
