How it works

Three steps, a few minutes.

Herdling works with herdr, the terminal workspace for coding agents. Each computer runs a small free companion, herdlingd.

  1. Install herdlingd on your computer

    On each Mac or Linux computer that runs herdr. One command sets it up as a background service for your user.

    herdlingd install

  2. Pair with a QR code

    Run the pair command and scan the code in the app. Your phone gets its own key, limited to Herdling.

    herdlingd pair

  3. Watch and steer your agents

    Your computers and their agents show on one board. Open one to read, reply, answer a question or start new work.

Terminal

The real terminal, one tap away.

Switch any agent to its live terminal. It works with every agent that herdr runs, including the ones without a chat view.

  • A key bar with Esc, Tab, Ctrl-C, the arrow keys and Enter.
  • Fit, wrap or scroll for wide output.
  • Interrupt an agent with Esc or Ctrl-C, from anywhere.

Notifications

A ping when it matters. Quiet when you are there.

Herdling tells you when an agent finishes or needs you. Tap the notification to open that session. While you work in herdr at your computer, Herdling stays silent, and for 5 minutes after.

  • Finished and Needs you, each with its own switch.
  • No noise from quick changes: herdlingd waits a few seconds before it sends.
  • Sent by your own computer, never by a Zog Tech server.

Your network, your computers

No accounts. No servers. Just SSH.

Herdling connects straight to your computers over SSH, on your Wi-Fi or through your own VPN. Your sessions, prompts, photos and recordings go from your phone to your computer and back. They never pass through Zog Tech.

  • No account to make, no login
  • No analytics, no ads, no tracking
  • The SSH key is made on the phone and stays there
  • The phone's key can only run herdlingd, not a shell
  • herdlingd runs as your user, not as root
  • Works away from home through WireGuard or Tailscale

Safe pairing

A six-digit code that works once, for 5 minutes. The app checks your computer's host key before it trusts it.

Questions

Something else? Read the guide or write to admin@zog-tech.com.

What do I need?

An iPhone with iOS 17 or later, or an Android phone with Android 8.0 or later. And one or more Mac or Linux computers that run herdr, an SSH server and herdlingd.

What does it cost?

Nothing. Herdling and herdlingd are free. There are no ads and no in-app purchases.

Which agents work?

Every agent that herdr runs shows on the board, with its status, its terminal and notifications. Claude Code, Codex, Pi and OpenCode also get the chat view, command lists and session resume.

Do I need herdr first?

Yes. Herdling shows the agents that herdr runs. herdr is made by its own project. When you set up a computer with its SSH password and herdr is missing, the app offers to install herdr with its official installer, only when you tap Install herdr and herdlingd. herdr must run when you use Herdling: start it with herdr in a terminal.

The app cannot connect to my new Mac.

On a new Mac, SSH is off. Turn on Remote Login: System Settings > General > Sharing > Remote Login. The phone and the Mac must also be on the same network or VPN. The app shows these steps when it cannot connect. The guide has them too.

Does herdlingd start when the computer starts?

It starts when you log in on the computer. To start it at boot, turn on automatic login on a Mac (not possible with FileVault on), or run sudo loginctl enable-linger $USER on Linux. The app shows a guide for this. See Start at boot.

Can I use it away from home?

Yes, if your phone can reach your computer, for example through WireGuard or Tailscale. Pair at home, then set the computer's address to its VPN address. You can also add a computer once with its SSH password.

Does Herdling see my code or my prompts?

No. Everything goes between your phone and your computer over SSH. Notifications go through Expo, Apple or Google and hold only the agent's name, kind and terminal title. The privacy policy has the details.

Is herdlingd safe to run?

It runs as your user, not as root. The phone's key can only run herdlingd rpc; it cannot open a shell. Pairing needs a six-digit code that works once, for 5 minutes, and the app checks the computer's host key.

How do I get herdlingd?

After the first herdlingd release, the app installs it for you: tap Set up with password, then Install and pair. A one-line installer does the same from a terminal. Today you can build it from the source code with git, Rust and four commands. The download page has the steps.

Is Herdling open source?

Yes. The app and herdlingd are open source under the MPL-2.0 license. The code is on GitHub.

How is Herdling different from other mobile agent apps?

Herdling is made for herdr. It shows one board of all the agents on all your computers, and a chat view read from the agents' own session files (Claude Code, Codex, Pi, OpenCode), with the live terminal one tap away. The phone connects straight to your computers over SSH: no account, no relay for your sessions, and the app is free and open source.

Other tools fit other needs. A plain SSH or Mosh client is enough if you want only a terminal. Moshi works with agents in any terminal, and Claude Code Remote Control is built into Claude Code. The README on GitHub has a dated comparison table.

Who makes Herdling?
